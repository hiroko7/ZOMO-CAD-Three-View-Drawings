# Rhino 模型读取与三视图适配

本流程只在用户已明确授权出图或导出时执行；隐式调用只可读取、分析和准备方案。必须使用已有的 Rhino MCP slot，先列出可用 slot 和当前文档，再由用户指定或确认目标 slot。没有已连接 slot 时，说明缺口并停止，不启动 Rhino、不创建替代会话。

## 读取顺序

1. 读取文档单位、世界轴向、命名视图、当前视图和模型包围盒；记录单位换算，不假定毫米。
2. 读取对象的 ID、名称、图层、材质、锁定/隐藏状态和块实例关系。若对象来自块，保留实例身份并记录源块定义。
3. 将用户所说“正面”与命名视图、轴向、入口/主要展示面交叉核对。存在多个可能正面或不能从模型判断时，先确认，不可自行选定。
4. 读取遮挡关系和可见边界后，按已确认的正、侧、顶正交方向生成二维投影；不以透视视图或渲染截图替代投影。

## 三视图任务规格

将每一个准备交给 CAD 的投影对象写入统一的**三视图任务规格**。每条至少包含下列字段：

| 字段 | 内容 |
|---|---|
| `role` | `front`、`side` 或 `top`，并注明其采用的已确认轴向 |
| `model-center` | 模型空间投影的中心点，采用 Rhino 文档单位 |
| `paper-rect` | 图纸空间中预留给该视图的矩形，采用纸张单位 |
| `custom-scale` | 模型单位到纸张单位的明确比例；不能由标准比例满足时记录自定义值 |

同时写入：源对象 ID、源图层、源材质、对象/块名称、可见性判定、投影曲线 ID 和预判语义线类。以上身份信息只写入任务规格或独立输出，不回写源模型。

## 曲线与输出

- 圆、圆弧、直线和多段线应按原始曲线类型保留；不要将圆弧离散成短线段。
- 仅在 CAD 目标或预设不支持样条时转换样条。转换前记录原对象 ID 与原因，转换后检查端点、闭合性、切线连续性和允许的偏差；优先使用满足图纸精度的最少控制点。
- 投影和清理结果进入独立输出层/独立导出对象集，按视图与语义分类命名；不得修改源对象、源图层、源材质、块定义或命名视图。
- 不得保存或关闭 Rhino 源文件。若需要保存导出副本、写入 DWG 或更改文件，先取得针对该输出目标的明确授权。

## 交接检查

交接前核查三视图中心、方向、比例、单位、曲线类型和对象身份是否齐全。效果图可用于确认构件外观和遮挡证据，但不能替代模型几何、单位、轴向或投影检查。
