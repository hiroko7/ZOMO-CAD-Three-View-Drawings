# 黑白打印预览规则

本 Skill 的施工图打印预览统一以 `黑白2.ctb` 为基准。随附文件位于 `assets/黑白2.ctb`，其 SHA-256 记录在 `assets/preset-manifest.json`。

## 使用顺序

1. 先检查当前 AutoCAD 能否解析名为 `黑白2.ctb` 的打印样式，并核对其 SHA-256；名称相同但校验值不同的文件不得静默当作 Skill 基准。
2. 若本机已有相同校验值的 `黑白2.ctb`，直接用于当前布局的打印预览。
3. 若本机没有该预设，将 Skill 随附的 `assets/黑白2.ctb` 复制到当前 AutoCAD 实际使用的 Plot Styles 搜索目录，再让 AutoCAD 重新读取打印样式。不得假定固定版本号、语言目录或用户名路径。
4. 复制属于对本机配置的写入：只有在用户已经明确要求打印预览、测试或出图时才执行；不要覆盖校验值不同的同名文件。遇到同名冲突时，保留原文件并报告冲突，取得用户同意后再处理。
5. 如果没有权限写入 Plot Styles 目录，可将随附 CTB 复制到本次项目的受控临时目录，并把该目录加入当前会话可访问的打印样式搜索路径；不得修改源 DWG、公司预设母版或系统范围配置来规避权限。
6. 应用 CTB 前递归检查块参照及嵌套块定义内实体的图层、Color/TrueColor、线型和线宽是否均为正确语义图层的 ByLayer；仅修正外层块参照不能保证黑白输出。
7. 预览完成后回读布局的打印样式名称，确认确实为 `黑白2.ctb`，再检查黑白线宽、文字、引线、图框、裁切和非打印对象。仅设置样式名称而没有生成并查看预览，不算完成检查。
8. 导出实际 PDF 或栅格预览后检查非预期彩色像素。应排除抗锯齿造成的近灰色边缘，但青、红、蓝等明显色相像素必须追溯到具体对象、图层或嵌套块并修正后重打；CTB 名称和哈希正确不能替代这一视觉验证。

## 边界

- `黑白2.ctb` 是打印预览与测试的默认基准，不代表已获授权保存 DWG、覆盖 PDF 或永久改变 AutoCAD 全局配置。
- 不得用 `monochrome.ctb`、灰度样式或自行推测的线宽映射冒充 `黑白2.ctb`。
- 若当前 AutoCAD 使用 STB 命名打印样式而无法直接应用 CTB，停止并说明，不要擅自转换图纸的打印样式模式。
