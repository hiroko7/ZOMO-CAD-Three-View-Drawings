# 尺寸与材质标注规则

标注的判断基准是目标图幅、视口比例、信息层级和最终黑白打印可读性。屏幕显示大小、模型空间单位或某一次项目的数值不能直接当作通用字号。

## 尺寸标注

1. 先确定各视口的最终打印比例，再选择公司预设中的对应标注样式；优先继承预设字体、颜色、图层、箭头和间距，不新建近似样式。
2. 按施工放样逻辑组织尺寸，避免只标总尺寸：
   - 外圈：总长、总高、总深及整体控制尺寸；
   - 中圈：主要分段、轴线、模块、柜体或构件定位；
   - 内圈：洞口、画框、层板、五金、收口及需要加工定位的局部尺寸；
   - 必要时补充标高、离地高度、进深和构造控制尺寸。
3. 总体尺寸与局部尺寸应形成清晰层级。总体尺寸通常放在实体外侧并可略大；局部尺寸若必须进入实体范围，应使用更紧凑的字号和间距，不能遮挡关键轮廓、材料分缝或其他数字。
4. 字高根据视口比例和图面密度确定，以打印后清楚、不过分抢图为准。例如在 `1:50` 视口中，外侧整体尺寸可约为 `2.5 mm` 纸面字高，实体中部的局部尺寸可约为 `2.0 mm`；这只是校准示例，不是固定数值。比例改变时需重新判断。
5. 修改异常标注时先检查对象级“文字高度”、标注样式及注释比例。若只是个别对象属性错误，直接修正该对象，不全局放大或重建全部尺寸。
6. 尺寸链应避免重复、矛盾和封闭链；施工所需的控制关系必须完整，装饰性或可由相邻尺寸直接推算且无放样意义的尺寸可省略。

## 材质与工艺标注

1. 材质文字、引线、字体、颜色和图层均继承公司预设；对象属性使用 ByLayer。新标注应先读取图中已有正确标注作为样式基准。
2. 文字高度同样根据视口比例、图面密度和打印可读性调整，不写死模型空间高度；与同一视口中的尺寸和图名形成协调层级。
3. 引线采用横平竖直的正交折线。引线端点准确指向对应构件，文字排列整齐；任意两条标注的文字、引线和转折不得相互叠压，也不得遮挡关键尺寸或轮廓。
4. 文字内容尽量简洁，优先写材料或成品名称及必要工艺，例如“香槟铜色金属线条”“白色饰面板”。厚度、规格、基层、固定和收口没有证据时不得补写。
5. “规格、基层及连接节点详见深化图”“颜色以封样为准”等适用于整张图的共性说明，每张图集中放置一次于不干扰视图的角落，不在每条引线上重复。
6. 排布优先利用实体外侧或视图留白，保持文字基线一致、引线转折有规律。空间不足时先精简文字和调整落点，再考虑缩小字号；不得为塞入标注而扩大到压过图形。

## 打印判定

完成后必须在目标图幅、实际视口比例和 `黑白2.ctb` 下查看预览。以预览结果判断字高、间距、线宽和重叠，不以彩色模型空间截图代替。发现问题时仅修正对应标注对象或样式属性，并重新预览受影响区域。
