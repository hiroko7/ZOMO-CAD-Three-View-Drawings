# 保存前三视图质量检查清单

所有项目在保存前逐项勾选并记录未通过项。只有检查和保存状态均通过，才能宣称图纸完成；若视觉检查未完成，必须明确仅完成了几何检查。

## 数量、范围与比例

- [ ] 正立面、侧立面、平面各一组，视口、图名块和比例文字数量对应。
- [ ] 每个视图的几何、尺寸、材质引线均在视口内完整可见，视口之间不能串图。
- [ ] 比例不是固定套用 `1:50`，而是由三个“几何＋尺寸＋引线＋文字”完整包围框和纸空间可用矩形反推；最受限视图决定共同候选比例。
- [ ] 三个视口的 CustomScale 完全相同，三处比例文字与其一致；任何例外均有用户明确批准。
- [ ] 三视图边对边、角对角并保持正确投影关系；应横向表达的平面/顶视图未被擅自旋转。
- [ ] 每组图名块与视口同宽、左右边界对齐；图名块缩放为 `1/1/1`，不同图名块无正面积重叠。
- [ ] 三组“视口＋图名块”的共同外边界等于图框净显示区，内部无缝隙、无正面积重叠；视口尺寸与中心用于适配。

## 视口、图层与线稿

- [ ] 完成排版后已执行视口锁定，并在锁定后复查视图隔离；每个视口只出现一个模型的一种视图。
- [ ] 每个视口的模型窗口与另外两组完整视图包围框零相交；移动视图时几何、尺寸、文字和引线作为完整包同步移动。
- [ ] 已清理或报告样条投影转换、重线、零长度线和异常碎线；真实圆弧仍被保留。
- [ ] 主要轮廓、次要轮廓、隐藏线、中心线、材质分缝、尺寸/引线按语义分层。
- [ ] 图层、颜色/TrueColor、线型与线宽均为预设要求的 ByLayer 表现；已递归检查块参照、块定义和嵌套块内实体，且没有把不同语义线稿压到同一图层。

## 尺寸、材料与图框

- [ ] 每个尺寸值均记录了几何端点、模型数据、既有可信尺寸或用户确认来源；没有依据截图、线条频率、视觉等分或效果图猜标。
- [ ] 尺寸不只包含整体尺寸：总尺寸、主要分段、定位、高度、进深及必要局部构造尺寸完整并按真实构件分块，且没有重复、矛盾或无意义封闭链。
- [ ] 尺寸文字高度已按视口比例和信息层级调整；外侧总体尺寸与实体内局部尺寸主次清楚，局部字号没有遮挡图形。
- [ ] 每条材料/工艺标注均有材料证据记录；已在当前项目范围内检查可用的 PDF、效果图、材料清单和同项目任务信息，缺失规格使用“待确认”“待现场核实”或“详见深化图”。
- [ ] 材质标注优先布置在视图上方；文字高度与共同视口比例匹配，字体、颜色、图层和线型继承预设；已数值检查引线仅含水平/竖直有效段、落点对应构件，标注之间无叠压，共性“详见深化图”类说明每张图只集中出现一次。
- [ ] 图框属性已填项目名称、图名、日期、比例、设计、制图、审核和版本；没有用独立文字覆盖。
- [ ] 预设母版未被写入、覆盖、清理或作为项目输出保存；记录了使用的预设版本与校验值。

## 输出与保存

- [ ] 打印预览使用 `黑白2.ctb`；本机缺少该样式时，已按 `print-preview-rules.md` 使用 Skill 随附副本，且未用名称近似但内容未知的 CTB 替代。
- [ ] 黑白预览已检查线宽层级、浅色线可见性、文字与引线清晰度、图框完整性及非打印对象；彩色模型空间显示不能替代此项。
- [ ] 已检查实际导出的 PDF/栅格预览不存在非预期彩色像素；`黑白2.ctb` 名称与哈希通过没有被当作这一项的替代证据。
- [ ] 输出是新的项目 DWG，路径、文件名和覆盖范围已获授权；源模型和预设母版均保持不变。
- [ ] 保存状态已由软件或文件系统回读确认，且检查报告与输出文件对应。
- [ ] 已导出可供视觉检查的 PDF 或图像，并检查裁切、线宽、比例文字、标题栏及引线可读性。
- [ ] 若受限而无法导出视觉检查图，已说明限制，未把未检查的视觉质量表述为通过。
