# SketchUp 模型读取与三视图适配

SketchUp 接入当前为**已设计、未验证**：在 MCP 连通性、可读能力和实际窗口状态均完成核验前，不得声称可执行 SketchUp 出图。本流程仍遵守项目总授权边界：只有用户明确请求出图、导出或修改时才可执行对应动作；隐式调用只做分析和方案准备。

## 能力和窗口核验

1. 先检查 SketchUp MCP 是否可用，并列出其读取、场景切换、相机、导出和写入能力；不要把能力假定为已可用。
2. 仅读取用户当前已打开的窗口和模型。没有现有窗口、MCP 不可连接或能力不足时，清楚报告缺口并停止。
3. **不得自动改用 Computer Use**，也不得因为 MCP 缺失而启动、接管或操纵 SketchUp。
4. **不得自动导入 Rhino**、转换模型或建立替代模型；此类跨软件动作需用户针对目标文件的明确授权。

## 读取模型的最小清单

读取并记录：模型单位、红绿蓝轴方向、场景（Scene）及相机类型、标签（Tag）可见性、组和组件层级、隐藏几何/隐藏对象、材质、剖切状态和模型整体包围盒。对象记录应保留实体/组/组件的持久标识或可追溯路径，避免把相同名称组件混为一体。

优先使用已经存在且相机为平行投影（正交）的正面、侧面、顶面场景。若没有合格场景，仅在明确授权的操作范围内准备正交三视图；“正面”与模型轴、入口、展示面或已命名场景不一致时必须询问用户。

## 三视图输出规格

每个正、侧、顶投影都写入统一**三视图任务规格**，以便 CAD 排版与审查：

| 字段 | 说明 |
|---|---|
| `role` | `front`、`side` 或 `top`，以及采用的已确认视向 |
| `model-center` | 该正交投影在模型空间的中心点，附模型单位 |
| `paper-rect` | 该视图在图纸空间预留的矩形范围，附纸张单位 |
| `custom-scale` | 从模型单位到纸张单位的比例；若不是预设比例，写出实际值 |

任务规格还必须包含：源组/组件路径、Tag、材质、可见/隐藏判断、场景名、投影曲线或边的标识、遮挡证据和预判语义线类。三视图仅用平行投影的几何结果，不能用透视截图代替。

## 输出边界

输出应为独立的视图对象集或导出副本，保留源对象身份；不改动用户模型、Tag、材质、场景、组或组件。任何保存、导出、修改场景或写回模型的动作，都要在执行前获得用户明确授权。效果图只可作为材质、构件外观和遮挡的辅助证据，不能取代模型中的尺寸、轴向、对象层级或可见性检查。
